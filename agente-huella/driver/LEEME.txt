COLOCA AQUI EL DRIVER DEL LECTOR
================================

El instalador busca en esta carpeta, por este orden:

  1. Un paquete con *.inf  -> se instala con `pnputil /add-driver ... /install`.
     Es la via preferible: sin instalador propietario y sin modificadores
     silenciosos que cambian de una version a otra.
  2. Un *.msi              -> `msiexec /i ... /qn /norestart`
  3. Un *.exe              -> se ejecuta tal cual

Driver conocido que funciona con este montaje:

    DigitalPersona 4500 Legacy / Non-WBF   v4.1.1.221   x64

Solo se instala si Windows NO reconoce ya el lector, y es el UNICO paso que
pide permisos de administrador. Si el equipo ya lo tiene, no se pide nada.

Sin driver el lector no existe para Windows y no hay software que lo arregle.
