¿Cómo funciona?

  1. Crea una plantilla para cada combinación EPS × Temporal (o "Todas") × Sexo (o "Ambos").
  2. En la pestaña Campos define qué {{'{{'}}Placeholder{{'}}'}} tiene el HTML y de dónde viene cada dato.
  3. En la pestaña HTML Plantilla pega el contenido HTML del formulario con los placeholders.
  4. Desde la tabla de Confirmación de Ingresos, el botón picture_as_pdf generará el PDF llenando automáticamente los placeholders.
  5. Para campos de firma (tipo render = FIRMA) el texto se muestra en fuente cursiva. Para imagen se inserta el sello/firma configurado en Config. Temporales.
